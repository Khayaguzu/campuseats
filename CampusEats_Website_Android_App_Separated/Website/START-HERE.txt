CAMPUSEATS: GENERAL FOOD ORDERING WEBSITE AND ANDROID APPLICATION

The website and Android app share the same PHP REST API and MySQL/MariaDB
database. Public registrations are CUSTOMER accounts. Store administrator
accounts are provisioned separately.

EXISTING INSTALLATION

1. Back up the current database and private Website/server/config.php.
2. Keep the existing PHP hosting paths and database connection details.
   Local Windows installs commonly use C:\wamp64\www\campuseats.
3. Do not reimport database/schema.sql or database/seed.sql into an existing
   database. Follow Website/docs/GENERAL-CUSTOMERS.md instead.
4. In phpMyAdmin, choose the existing database and run
   Website/database/general_customers_migration.sql.
5. If the order_payments table is missing, review
   Website/database/payment_migration.sql and apply it only as needed.
6. Deploy the updated Website/web and Website/server files together. Preserve
   the existing private config.php and remove the old college-logo.png
   from the hosting file manager.
7. In a local WampServer checkout, start Apache and MySQL and visit
   http://localhost/campuseats/CampusEats_Website_Android_App_Separated/Website/web/
   when using the repository's complete nested folder structure.
8. In Android Studio open Android_App directly, not the repository root.
   The Android app loads the same hosted interface and database-backed API.
9. Verify account creation, login, basket, orders and administrator permissions.
   For real phone testing, configure both Android URLs to the working HTTPS
   website and rebuild the APK.

GOOGLE SIGN-IN AND PAYMENTS

Google authentication requires private OAuth credentials and a verified HTTPS
callback. Follow Website/docs/SSO-DEMONSTRATION.md before demonstrating login
on both platforms. Never commit credentials to GitHub.

A configured demonstration checkout charges no money. Real payments require
PayFast configuration and independent end-to-end verification. Do not treat
a demonstration confirmation as evidence of money received.

For installation, API and testing details, read Website/README.md.
