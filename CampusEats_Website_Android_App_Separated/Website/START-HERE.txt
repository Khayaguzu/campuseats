CAMPUSEATS: SEPARATED WEBSITE AND KOTLIN ANDROID PROJECT

1. Keep the current Git checkout in C:\wamp64\www\campuseats.
   In this layout, the website is inside CampusEats_Website_Android_App_Separated\Website.
   Keep your current working server\config.php and MySQL port 3308.
2. Start Apache and MySQL in WampServer.
3. On an EXISTING database, do not reimport schema.sql or seed.sql; export a backup first.
4. Keep your existing private Website/server/config.php and add the payments block if needed.
5. From C:\wamp64\www\campuseats, run the PHP CLI administrator setup:
   php server\create-admin.php admin@example.com "Campus Administrator" "YourStrongPassword123!"
6. Open http://localhost/campuseats/CampusEats_Website_Android_App_Separated/Website/web/ in a browser.
7. Open Android_App in Android Studio. The emulator uses 10.0.2.2 to access WampServer.
8. To use a real phone, update Android_App/gradle.properties for the computer's LAN IP and full /Website/web/ path, enable Apache private-network access, and rebuild the APK.
9. For Google SSO, follow Website/README.md and configure both Google credentials and the OAuth callback.

Existing features, roles, menus, stock management, orders and student discounts are preserved.
For detailed steps and troubleshooting, read Website/README.md.

AUTOMATIC PAYMENT UPDATE FOR EXISTING DATABASES

- Back up the existing campuseats database in phpMyAdmin before modifying it.
- Run Website/database/payment_migration.sql against campuseats on MySQL port 3308.
- Keep the existing server/config.php and credentials; copy in only the payments settings.
- New orders do NOT offer manual EFT payment or administrator payment approval.
- For real payments, configure PayFast merchant credentials and a public HTTPS callback.
- For LOCAL DEVELOPMENT ONLY, set payments.demo.enabled to true to simulate payment.
  No real funds change hands and the demo is restricted to the local machine.
- Once the payment provider confirms payment (or simulated test is completed),
  the collection number appears under My orders. Unpaid orders cannot be collected.
- Role approval remains only for verified student discounts or administrator accounts,
  and is not required for ordinary student or lecturer purchases.
- See Website/README.md for payment configuration and full security notes.
